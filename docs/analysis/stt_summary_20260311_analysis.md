1. 고객 요청 사항을 첫 줄에 배치
2. 계약자/피보험자/배우자 등 관계 정보 우선 반영
3. 상담사의 처리 결과, 후속조치, 문자/콜백/전달 안내 반영

1. 고객명, 생년월일, 주소, 전화번호 등 개인정보
2. 업무 핵심이 아닌 세부 시각, 상세 금액, 증권번호
3. 단순히 STT에 있다는 이유로 넣는 부가 설명
4. 오전사 가능성이 있는 혼입 문구의 무비판 반영
