# Qwen3 / Qwen3.5 / GPT A/B 평가 포맷

## 목적

Qwen3-Instruct, Qwen3.5-Instruct, GPT 계열 모델의 보험 상담 요약 성능을 같은 기준으로 비교하기 위한 평가 포맷이다.
평가 기준은 문장 자연스러움보다 근거성, 누락 방지, 주체 보존, 상태 보존을 우선한다.

## 평가 대상

- 모델 A: Qwen3-Instruct
- 모델 B: Qwen3.5-Instruct
- 모델 C: GPT 계열
- 동일 입력: `source_text`, `source_text_cleaned`, `audio_preprocess`, `stt_preprocess`, `feedback_rules`, `analysis_hints`, `prompt_improvement_rules`
- 동일 출력 형식: `[상담요약]` 항목형
- 권장 비교 조건: `summary_strategy=speaker_staged`

## 평가 항목

1. 사실 정확성
- 원문에서 직접 확인 가능한 사실만 썼는가
- 상태, 수치, 가능 여부를 바꾸지 않았는가

2. 핵심 정보 누락 방지
- 고객 요청 사항이 드러나는가
- 처리 상태가 드러나는가
- 상담사 후속조치가 드러나는가
- 관계 정보가 필요할 때 반영되는가

3. 주체 보존
- 계약자, 문의자, 피보험자, 보장 대상 주체가 혼동되지 않는가
- 본인 계약 문의를 다른 피보험자 계약으로 바꾸지 않는가
- 고객 발화와 상담사 발화가 섞이지 않는가

4. 비핵심 정보 억제
- 개인정보를 제거했는가
- 정답지에 없는 비핵심 STT 부가정보를 과하게 추가하지 않았는가
- 오인식 표현을 그대로 쓰지 않았는가

5. 실무 적합성
- 고객 요청과 후속조치가 분리되어 보이는가
- 처리 상태가 모호하지 않은가
- 검수자가 빠르게 읽고 사용할 수 있는가

## 단계형 추가 평가

발화자 단계형 요약을 쓸 때는 아래 3단계로 추가 점검한다.

1. 고객 요약
- 문의 목적 누락 여부
- 핵심 질문 누락 여부

2. 상담사 요약
- 안내 내용 누락 여부
- 후속 조치 누락 여부

3. 최종 통합 요약
- 역할 혼동 여부
- 전체 흐름 정리 여부

## 점수 체계

각 항목 1~5점
- 1점: 실무 사용 불가
- 2점: 결함 반복
- 3점: 기본 사용 가능하나 오류 존재
- 4점: 실무 사용 가능, 소폭 개선 여지
- 5점: 안정적

권장 가중치
- 사실 정확성: 30
- 핵심 정보 누락 방지: 25
- 주체 보존: 20
- 비핵심 정보 억제: 15
- 실무 적합성: 10
